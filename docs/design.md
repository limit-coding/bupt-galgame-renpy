# 设计与实现

## 方向

传统 2D Ren’Py 视觉小说。原有 3D 校园工程保留在父目录，本工程没有依赖它，也不使用其图片或模型。人物与事件均为虚构；不把占位建筑标为真实布局。

## 核心叙事

主题：允许自己从“不知道”开始。贯穿物是一张声音日记卡；三个分支分别以书页、敲击和杯声连接同一主题。所有路线都回到傍晚，显示不同记忆与关系状态。

| 角色 | 暂用名 | 设定 | 状态变量 |
|---|---|---|---|
| 主角 | 许言 | 第一人称北邮新生 | protagonist_name |
| 同班同学 | 林晴 | 开朗，紧张时会多说话 | classmate_name / affection_b |
| 实验室学姐 | 沈知遥 | 理性，承认不确定性 | senior_name / affection_c |

姓名可在 `game/characters.rpy` 中替换。主角不强制显示立绘，但预留了完整五表情。所有好感和分支状态使用 Ren’Py default，支持存档和回退。

## 表现

1280×720；主色为深蓝灰、薄荷绿，暖米色强调。正文 26 px；底部半透明对话区保留约 200 px；所有资源由原生图像/变换系统管理。没有另建存档系统或媒体播放器。

`script.rpy` 的 start → library_event / lab_event / cafeteria_event → evening_scene 构成闭环。`audio.rpy` 在播放前检查资源存在。`theme.rpy` 负责主题覆盖，基础菜单沿用 SDK 中文模板。

季节变化不影响主体流程。后续同一 scene ID 可增加 spring/summer/autumn/winter 版本，并单独登记照片来源；本轮不实现四季切换，先完成真实照片主版本。

## 未完成的质量目标

正式日式立绘、真实照片背景、音乐、完整 10–20 分钟真人节奏测量仍属于后续。当前可以作为功能原型试玩，不能宣传为最终商业美术品质。
