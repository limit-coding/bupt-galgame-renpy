# 北邮物语：开学第一天 v0.4.0

Ren’Py 2D 校园视觉小说 Demo。包含五场景结构、图书馆／实验室／食堂三条分支、七张北邮西土城实景参考动漫背景，以及 DeepSeek／GPT／Claude 娘三套六表情立绘。

## 下载与启动

- Windows：下载 `BUPTStories-0.4.0-win.zip`，完整解压后运行 `BUPTStories.exe`。
- macOS：下载 `BUPTStories-0.4.0-mac.zip`，解压后打开 `BUPTStories.app`。应用未签名及公证；如系统阻止，在确认下载来源后使用系统“仍要打开”流程。
- 源码：下载 `BUPTStories-0.4.0-source.zip`，解压后使用 Ren’Py 8.5.3 SDK 启动工程。Windows/macOS 玩家包已自带运行环境。
- `SHA256SUMS.txt` 提供三个下载包的 SHA-256 校验值。

鼠标左键／空格推进；Esc 打开菜单；H 隐藏对话框。支持保存、读取、历史、回退、自动及快进。主菜单“美术预览”可查看角色表情与校园背景。
